# ForgePY F108-F207 Gap Audit

## Closed / materially advanced

- Workspace control geometry and command taxonomy are normalized without changing ForgePY's visual identity.
- Vault now has explicit browser classification, search, lineage and non-destructive safety models.
- Tooling has typed contracts, safe probe support, execution policy, promotion scopes and richer generated adapters.
- Artifact Central has a persistent searchable SQLite index model and ForgePY has unified activity/receipt authorities.
- Project families/composite roots have an explicit graph model instead of relying on flat discovery alone.
- Shared state, refresh debounce, console buffering and pagination primitives now exist as reusable performance foundations.
- Settings/security/plugin/adapter/job/automation/retention/backup/template/diagnostic/provenance/dependency/release models are now first-class ForgePY modules.
- Standalone EXE and transactional EXE replacement are specified in executable build/state-machine code without claiming Windows certification that has not happened.

## Still requires the Windows host

1. F60R67 startup-surface lifecycle smoke test.
2. Native one-file Nuitka build of ForgePY.exe.
3. Windows SmartScreen/Defender behavior for the produced executable/update mechanism.
4. Native tray replacement/certification.
5. Clean-PC first-run UI and dependency installation approval workflow.
6. Real self-replacing executable handoff/rollback test.
7. Filesystem watcher long-duration certification on D:.
8. Visual verification of compact quick actions, right-rail width and Workspace splitter defaults at the user's monitor resolution.

## Deliberately not automatic

- Non-patch file moves/deletes.
- Dependency/toolchain installation without operator approval.
- Plugin auto-enable.
- Scheduled automation execution.
- Retention cleanup/deletion.
- Source-control force operations.
