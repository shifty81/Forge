# Standalone Package Changelog

## PCC-STANDALONE-0.1 / PCC-GUI-0.10.2 — 2026-09-09

- Portable launcher independent of any registered project repository.
- Reuses the current three-panel Project Workspace GUI.
- Compact separated health monitor in the Project Workspace header.
- Persistent right-side embedded project console.
- Projects registry and folder-first automatic onboarding.
- Project JSON not required for onboarding.
- Universal auto-adapter for existing project command/root utilities.
- Universal repo prepare/finalize hygiene around governed operations.
- Vault / Forge project catalog and file browser foundation.
- Semantic console coloring for PASS/FAIL/WARN/ERROR tokens.
- Cortex project-side PCC recovery/reference snapshot included.
